# Lore History and Artifacts

This is the trace side of the Hearthline lore shelf.

The present story is one level up in [`lore/`](../README.md). If a later tale replaces, corrects, or substantially reframes one of those texts, the displaced version or a clear provenance note belongs here rather than remaining mixed into the current reading path. Git preserves the exact byte history as well.

No prose artifact has been displaced in this first lore publication. The room is intentionally empty except for its label: even an unused path home is worth naming before it is needed.

Historical status does not mean false, shameful, or disposable. It means the work can be found without being mistaken for the current telling.
