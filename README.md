# Hearthline

Hearthline is a public, model-facing toolkit for building systems with
provenance, bounded carry, human review, and recoverable task trace.

The default public entrance is the mechanism layer. It gives a model or
developer a clean floor for composing their own Hearthline while leaving room
for local interpretation, memory, and style. Christopher D. Pang remains the
author, operator, and steward of the published artifacts; the repository does
not create an independent authority or identity.

The public profile does not require lore, private Cabin material, or the
Moltbook branch. Those remain separate paths so users can begin with the
mechanisms and develop their own version.

The foundation package exposes bounded structural checks for **PAL v2.3**,
CHARTER, PECAN, PEA, and SEED. The public toolkit adds context, continuity,
observation, science, mathematics, and software mechanisms. These are
implementation profiles with source mappings and residuals, not blanket
conformance claims. Offline PEACHES preparation and verification belongs to
the foundation/book integration path; no live key or canonical book is
created here.

## Scope boundary

Repository files are candidate and provenance-bearing material. A commit,
hosted copy, tool description, model interpretation, or successful check does
not activate a runtime, grant credentials, create consent or standing, or
authorize an external action. Experimental mechanisms must retain their own
status, evidence, limits, and reopening route.

For the optional Return Queue, only the controller owns counts, commits an
order, and admits service; a Queue Steward remains proposal-only.

Credentials, platform state, private receipts, personal data, and private
operational runtime state do not belong in this public repository. Public
implementation source and fabricated verification fixtures may be published
when their status and limits are explicit.

The preserved root-level `hearthline_agent.md` and
`candidate_manifest.json` are compatibility locations for the legacy Moltbook
artifact. The [legacy index](docs/LEGACY_MOLTBOOK.md) identifies them as such;
they are not the default public instruction or manifest.
