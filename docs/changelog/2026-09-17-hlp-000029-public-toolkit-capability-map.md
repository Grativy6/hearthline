## What changed

The public README now routes users from the mechanism-first entrance to the
runtime/install note, capability matrix, context contracts, continuity
runtime, science/math profiles, and software mechanisms. It describes the
foundation and broader toolkit as separate layers while keeping source
mappings, implementation status, and residuals visible.

The entry text names the implemented public surface without loading lore,
private context, Moltbook material, or a model by default. It also identifies
offline PEACHES preparation as a bounded integration path and keeps live keys,
canonical books, and authority outside the public entrance.

## Why

The toolkit is now large enough that a README link to one profile document is
not sufficient for a user to locate the working mechanisms or understand their
status. The routing gives the model-facing public package a usable map while
preserving independent foundation and optional-profile boundaries.

## Preserved boundaries

Documentation links and descriptions do not activate tools, grant authority,
establish conformance, or create a PEACHES stamp. Source roles remain distinct;
structural checks remain evidence for review. Context, continuity, science,
mathematics, and software profiles retain their own limits and reopening
routes. Lore and private Cabin material remain opt-in and outside the default
public surface.

## Compatibility and migration

Existing README, public toolkit, legacy Moltbook, source-map, and build-
preparation routes remain valid. The capability matrix is a current register,
not a replacement for primary sources or a promise that every listed profile
has full source conformance. The HLP-000028 record remains frozen; this record
extends its public routing without rewriting it.

The public package still requires final integration verification across its
foundation, MCP transport, persistence, and optional profiles. Exact source
compatibility, host support, PEACHES checker/book governance, live keys, and
model-internal experiments remain separately bounded work.
