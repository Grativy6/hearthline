## What changed

Added the compact founding orientation, **Love; Seed, not Feed; Honest**, to
the MCP server's initialization instructions. One package constant supplies
all existing server profiles. Linked the portable wording from the public
entrance and documented its delivery boundary.

## Why

Christopher requested that the orientation be up front in the MCP connection,
not merely stored in repository documentation or behind an optional tool.
Seed offers paths without prescribing a destination: play, comfort, exploration,
and declared fiction remain valid purposes.

## Preserved boundaries

The orientation claims no feelings, consciousness, standing, or authority.
PAL, CHARTER, PECAN, PEA, and SEED retain their distinct source roles. No tool,
permission, profile, private record, or model is added. The larger template
remains opt-in; ordinary conversation does not inherit a game contract.

## Compatibility and migration

The pinned MCP implementation supports the standard optional `instructions`
field. Updated servers send it on initialization. Installed clients need an
updated package and a new connection; the host decides how to carry the guidance
to its model. This history record itself activates nothing.

## Verification observations

Focused regressions cover exact documentation/runtime wording parity and the
real stdio initialization response for each existing profile, with template
opt-in disabled. Full toolkit tests and the existing structural checks remain
the verification route for this change.

## Open residuals

Delivery is not proof that a client displays the guidance, that a model follows
it, or that model capability has improved. Already-running installations are
not updated by publishing source.

## Evidence and exclusions

This update changes the source-defined opening instructions, not model weights.
No training, dream loop, game run, credentials, private conversation, or
competition action is included. Earlier records and unrelated local work are
preserved.
