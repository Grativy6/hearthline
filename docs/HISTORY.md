# Reading the public history

The current repository is the public systems lab. Character art, personal lore
and the legacy agent draft have been retired from its current tree after their
exact originals were verified in separately controlled private preservation.
No private content or destination map is published here.

Previously public material remains public in Git history. This change does not
erase that history or make it confidential. To read original stories, images,
mixed documents and their relative links, use the
[pinned pre-split tree](https://github.com/Grativy6/hearthline/tree/f5c69b912761f29e2c82f83d1fe412fc83ec873a).

All earlier full [change records](../CHANGELOG.md) keep their exact bytes and
IDs. A record's original relative artwork or story link may no longer exist in
the current checkout; the
[original change index](https://github.com/Grativy6/hearthline/blob/f5c69b912761f29e2c82f83d1fe412fc83ec873a/CHANGELOG.md)
opens the records in the version where those links resolve. Current technical
documents use current paths. The [legacy Moltbook index](LEGACY_MOLTBOOK.md)
likewise offers explicit versioned links.

The [public split manifest](history/public-lab-split.json) binds each retired
or technically edited source to its already-public path, Git blob and SHA-256.
It also locks the 23 CPX companion files and 27 earlier full change records.
The [checks](VERIFYING.md) inspect the pinned public Git objects, retain legacy
digest and non-adoption checks, and reject missing links in current documents.
They do not need private repository access.

The [branch archive](changelog/branch-archive.json) retains its original
identities, reservations and non-adoption limits. Its references to canonical
mainline artwork describe the recorded historical tree; they do not require
the artwork to be part of today's package.
