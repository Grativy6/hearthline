## Route discipline

1. Select the exact repository, branch, and commit.
2. Read its local instructions, status, source lock, and run entry.
3. Verify the declared blocker and human gates again.
4. Keep public preparation distinct from private staging and official execution.
5. Preserve exact receipts and return a bounded result.

No route in this document authorizes credentials, private data access, an official environment, holdout consumption, submission, publication, or a score claim.
